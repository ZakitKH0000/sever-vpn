# Проверка первой сборки на iPhone

Целевое устройство: iPhone с iOS 17 или новее. Точную модель и номер iOS нужно
записать в локальном отчёте при проверке.
Выполненные пункты отмечаются только по фактическому результату на устройстве.

- [ ] Установка подписанного IPA с двумя вложенными VPN-расширениями.
- [ ] Сохранение разрешений Network Extensions и общей группы Keychain при подписи.
- [ ] Запуск без импортированной подписки и получение бесплатного каталога.
- [ ] Подключение к доступному OpenVPN-узлу VPN Gate.
- [ ] Проверка трёх тестовых адресов через туннель.
- [ ] Импорт полного Xray-профиля и запуск Xray-расширения.
- [ ] Восстановление связи после смены Wi-Fi на LTE и обратно.
- [ ] Блокировка и разблокировка экрана; длительная работа в фоне.
- [ ] Недоступность текущего узла и переход к следующему OpenVPN-кандидату.
- [ ] Недоступность всех узлов: подтверждённое отсутствие прямого выхода
      по IPv4, IPv6 и DNS. Одного изменения публичного IP недостаточно для проверки.
- [ ] Принудительное завершение VPN-процесса, перезапуск приложения и устройства.
- [ ] Явное отключение VPN пользователем снимает автоматическое подключение.
- [ ] Обновление каталога не прерывает уже работающий туннель.
- [ ] Ошибка источника оставляет сохранённые профили доступными.
- [ ] Импорт из Files и вставка ссылки без случайного отображения секретов.
- [ ] Без настроенного ИИ нет запросов к ИИ-сервисам.
- [ ] После нажатия «Проанализировать» отправлены только разрешённые поля отчёта.
- [ ] Замер памяти VPN-расширения и расхода батареи при длительной нагрузке.

Если какой-либо пункт не пройден, результат фиксируется с номером сборки
и условиями воспроизведения. Готовность для повседневной работы пока не подтверждена.
