# Север

Личный VPN-клиент для iPhone: бесплатный каталог VPN Gate, импорт собственных
профилей, проверка связи и необязательная помощь ИИ по нажатию кнопки.
Компактный тёмный интерфейс на SwiftUI, iOS 17 и новее.

**Статус: первая тестовая версия 0.1.0 собрана в Xcode. Создан неподписанный
IPA для iPhone (arm64, iOS 17+). Установка и работа на физическом iPhone
ещё не проверены.**

[Успешная сборка IPA](https://github.com/ZakitKH0000/sever-vpn/actions/runs/41515631242)
· [Установка и первый запуск](INSTALL.md)

## Что сделано

- Три экрана: подключение, серверы, проверка связи.
- Получение до 30 бесплатных TCP/OpenVPN-узлов из публичного каталога VPN Gate.
  Страны чередуются, чтобы одна страна не занимала весь список.
- Импорт полного Xray JSON, массива полных конфигураций, ссылок VLESS/Trojan,
  Base64-списков и OpenVPN с сертификатами внутри файла.
- HTTPS-подписки с обновлением при открытии приложения, если прошло больше часа.
  Обновление не требует новой сборки приложения.
- Выбор бесплатного сервера по отклику TCP, до четырёх проверок одновременно.
  Это проверка доступности порта, а не тест VPN или скорости загрузки.
- Два независимых VPN-расширения: OpenVPN и Xray. Одновременно используется
  только одно ядро. Для OpenVPN подготовлен переход между тремя сохранёнными
  узлами; полные Xray-профили могут использовать собственные балансировщики.
- Строгая маршрутизация без намеренного прямого резервного выхода. В импортируемой
  копии Xray прямые правила убираются, резервные выходы заменяются блокировкой.
  DNS настраивается приложением. Исходные конфигурации сохраняются без изменений.
- Зашифрованное AES-GCM хранилище профилей; ключ и настройки ИИ находятся в Keychain.
- Три фиксированных адреса проверки: Cloudflare, Google, Apple.
- ИИ получает только разрешённые поля отчёта и только по кнопке
  «Проанализировать». Автоматического изменения настроек по ответу ИИ нет.

## Бесплатные серверы

[VPN Gate](https://www.vpngate.net/en/) публикует CSV-интерфейс специально
для сторонних клиентов. Серверы предоставляют добровольцы; они не связаны
с оплаченной подпиской пользователя. В исходники не встроены платные ключи.

Наличие сервера в каталоге не гарантирует его доступности, скорости или
работы в конкретной российской сети. Владельцы узлов ведут журналы соединений;
это не сервис с обещанием отсутствия журналов. Разные страны присутствуют
только если их совместимые узлы есть в текущем каталоге. Пользовательский
импорт позволяет дополнить список другими источниками.

Доступ к любому внешнему бесплатному источнику остаётся зависимым от его
владельцев. Приложение не создаёт собственную зарубежную инфраструктуру.

## Ограничения первой версии

- Для Xray JSON с `geoip:`, `geosite:` или `ext:` нужны геоданные; такие
  профили пока отклоняются. Защита TLS не отключается ради совместимости.
- Ссылками напрямую импортируются VLESS и Trojan. Для других поддерживаемых
  ядром протоколов нужен полный JSON; совместимость конкретного профиля
  определяется проверкой закреплённой версии ядра.
- OpenVPN: встроенные CA/клиентские сертификаты и ключи; внешние файлы и скрипты
  не поддержаны. Ввод личного OpenVPN-логина, пароля и пароля к закрытому ключу
  пока не реализован. Публичные реквизиты `vpn/vpn` используются только для VPN Gate.
- Собственные зашифрованные форматы провайдеров, Age, HWID и Premium API
  Happ/INCY не реализованы. Секретная подписка должна отдавать обычный
  поддерживаемый формат. Междоменные HTTP-перенаправления отклоняются.
- Обновление каталога/подписок выполняется в открытом приложении. Постоянное
  обновление в фоне не обещается. Проверки Xray и переподключение выполняются
  работающим VPN-расширением.
- Состояние «Туннель включён» не означает, что каждый интернет-сервис доступен.
  Для подтверждения используется отдельная проверка связи.
- Блокировку трафика при сбое процесса, блокировке экрана, смене Wi-Fi/LTE,
  IPv6 и отключении VPN из системных настроек нужно проверить на iPhone.
  До этого нельзя обещать отсутствие всех утечек iOS.
- ИИ необязателен. Нужен собственный совместимый HTTPS API с форматом
  `chat/completions`, ключ и название модели. Бесплатность зависит от тарифа
  выбранного сервиса; приложение само не запрашивает ИИ в фоне.

## Что проверено

- 12 тестов того же JS-обработчика, который включён в iOS-приложение.
- Синтаксис 13 Swift-файлов и двух вариантов Objective-C расширения:
  локальная проверка парсером. После исправления двух объявлений SwiftUI
  также успешно выполнена настоящая сборка Xcode на macOS.
- Тот же обработчик успешно исполнен в JavaScriptCore на macOS.
- Xcode собрал приложение и оба VPN-расширения. Скачанный IPA проверен:
  все три исполняемых файла имеют архитектуру arm64 и минимум iOS 17.0;
  обработчик конфигураций, иконка и лицензии включены в приложение.
- YAML проекта и сборки; отдельные VPN-расширения с общей группой Keychain.
- Официальный LibXray v26.10.31 скачан и сверен с SHA-256 релиза.
- Публичный API VPN Gate ответил HTTP 200; найдено 30 совместимых профилей.
  VPN-сессии с этими узлами не устанавливались.
- Присланный образец прочитан локально: семь узлов сохранены, прямой выход
  в подготовленной копии отключён. Параметры доступа не записаны в исходники.

## Сборка и установка

Подготовлен [процесс сборки GitHub Actions](.github/workflows/build-ios.yml).
Он создаёт неподписанный `Sever-unsigned.ipa` на стандартном macOS runner.
Для публичных репозиториев стандартные runners
[предоставляются бесплатно](https://docs.github.com/en/actions/concepts/billing-and-usage).
Платные runners и облачные серверы для этой сборки не нужны.

Репозиторий создан и код опубликован с разрешения пользователя.
Пользователь подписывает IPA своим способом.
Нужно подписать приложение и оба расширения, сохранив разрешение
`packet-tunnel-provider` и одинаковую группу Keychain во всех трёх целях.

Для ручной сборки на Mac с Xcode и XcodeGen:

```sh
npm test
swift scripts/check_javascriptcore.swift
python3 scripts/prepare_dependencies.py
xcodegen generate
xcodebuild archive -project Sever.xcodeproj -scheme Sever \
  -configuration Release -destination 'generic/platform=iOS' \
  -archivePath build/Sever.xcarchive \
  CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO CODE_SIGN_IDENTITY=''
python3 scripts/package_ipa.py build/Sever.xcarchive build/Sever-unsigned.ipa
```

Сборка требует интернета для получения закреплённых зависимостей.
Не загружайте личные конфиги, сертификаты подписи или API-ключи в GitHub.
