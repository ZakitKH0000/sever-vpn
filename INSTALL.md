# Установка «Севера» 0.1.2

Это тестовая сборка. Она успешно собрана Xcode и прошла проверки каталога
в симуляторе, но ещё не испытана на физическом iPhone. Файл IPA нужно подписать
перед установкой. По возможности устанавливайте обновление поверх предыдущей
версии с теми же идентификаторами и командой подписи, сохраняя её данные.

1. Откройте IPA в своём инструменте подписи.
2. Подпишите приложение **вместе с двумя вложенными VPN-расширениями**.
   Используйте одну команду разработчика для всех трёх компонентов.
3. Установите приложение на iPhone и откройте «Север».
4. Откройте «Серверы»: стартовый список из 30 публичных узлов
   уже включён в приложение. Обновить его можно кнопкой «Обновить бесплатные
   серверы». При сбое причина будет указана на этом же экране, а список останется.
5. Нажмите «Подключиться». В системном запросе iOS на добавление VPN
   нажмите **«Разрешить»** и подтвердите действие на телефоне, если потребуется.
6. После подключения откройте «Проверка» → «Проверить доступ в интернет».

Показатель «Туннель включён» означает состояние VPN-подключения iOS.
Доступ в интернет подтверждают результаты отдельных проверок.
Бесплатные серверы VPN Gate могут быть недоступны в конкретной сети:
в этом случае обновите каталог и попробуйте другой узел.

ИИ для подключения не нужен. Настройте его позже, если захотите:
запрос отправляется только после нажатия «Проанализировать».

Если на экране указана ошибка Keychain с числовым кодом, это отдельная
ошибка сохранения или доступа к конфигурации. Она больше не выдаётся за
ошибку загрузки VPN Gate. Публичный список при этом остаётся виден.

## Требования к инструменту подписи

Подпись должна поддерживать `packet-tunnel-provider` для обоих расширений
и одинаковую группу Keychain у приложения и расширений. Отдельно сохранять
ключи VPN в IPA не нужно: приложение передаёт выбранный профиль через Keychain.

Идентификаторы исходной сборки:

- `dev.sever.vpn` — приложение;
- `dev.sever.vpn.XrayTunnel` — расширение Xray;
- `dev.sever.vpn.OpenVPNTunnel` — расширение OpenVPN.

Версия 0.1.2 определяет идентификаторы расширений по их установленным Info.plist,
в том числе если инструмент подписи меняет исходные идентификаторы.
Общая группа Keychain: `<префикс команды разработчика>dev.sever.vpn.shared`.

Если VPN не запускается, прочитайте последний этап и ошибку под кнопкой
«Подключиться». Дополнительно откройте «Проверка» → «Получить причину
отключения iOS». При ошибке Keychain проверьте одинаковую группу у приложения
и обоих расширений. Если расширение отсутствует, инструмент подписи должен
сохранить и подписать его. Если сервер не отвечает, обновите каталог.

Сохраните точный текст ошибки и укажите, запускался ли бесплатный OpenVPN-профиль
или импортированный Xray-профиль. Ключи и секретную ссылку подписки
для этого присылать не нужно.
